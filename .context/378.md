# Context package — Issue #378

## Issue summary

Treat test binaries (`#[test]`, BDD step-attrs, `#[bench]`, files under `tests/` and `benches/`) as `:EntryPoint` nodes so cfdb's reachability BFS recognises test-only callers, eliminating false-positive `Unwired` classifications on adapter code that is tested-but-not-production-wired. Acceptance hints reference a measurable drop of `cfdb scope --context trading --keyspace qbot-core` `unwired` count from 2057 to low-hundreds, with a new `--production-only` flag preserving the historical view.
